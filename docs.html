1. Visão Geral do Sistema

1.1 Descrição do Projeto

O Wash Wizard é um sistema ERP (Enterprise Resource Planning) modular desenvolvido para gestão de lava-rápidos. O sistema automatiza o workflow operacional incluindo controle de clientes e frotas, gestão de lavagens, controle de estoque de produtos e dashboard financeiro com métricas de negócio.

1.2 Escopo e Aplicação

Desenvolvido como projeto acadêmico para a UNIVESP - Engenharia de Computação, o sistema opera em modo local/offline utilizando SQLite como banco de dados relacional, garantindo total independência de conexão com internet durante a operação comercial.

1.3 Funcionalidades Principais

  • • Gestão de clientes e veículos (CRUD completo)
  • • Registro e acompanhamento de lavagens
  • • Cadastro de tipos de lavagem com preços
  • • Controle de estoque de produtos
  • • Movimentações de entrada/saída de estoque
  • • Dashboard financeiro com gráficos
  • • Backup e restore via CSV

1.4 Usuários do Sistema

ADMIN Administrador com acesso completo: clientes, lavagens, estoque, configurações e backup.
OPERADOR Operador com acesso restrito: clientes e lavagens (visualização e registro).

2.2 Frontend (Client)

  • Framework: React 18 + TypeScript
  • Build Tool: Vite 8.x
  • UI: Tailwind CSS + shadcn/ui
  • Estado: React Context + TanStack Query
  • Routing: React Router DOM v6
  • Gráficos: Recharts
  • Code Splitting: Lazy/Suspense

2.3 Backend (Server)

  • Runtime: Node.js 18+
  • Framework: Express.js
  • Database: SQLite3 (sqlite3)
  • Parser: csv-parse / csv-stringify
  • Upload: Multer
  • CORS: Enabled
  • Porta: 3001

2.4 Banco de Dados

  • SGDB: SQLite 3
  • Arquivo: wash_wizard.db
  • Constraints: Foreign Keys ON
  • Transações: Suportadas
  • Backup: CSV Export/Import
  • Schema: schema.sql
  • Seed: seed.js

4. API REST

4.1 Endpoints Principais

GET /api/clientes Lista todos os clientes
POST /api/clientes Cria novo cliente
Body: { "user_id", "nome", "telefone" }
PUT /api/clientes/:id Atualiza cliente
DELETE /api/clientes/:id Remove cliente

4.2 Recursos de Veículos

  • GET /api/veiculos
  • GET /api/veiculos?cliente_id=X
  • POST /api/veiculos
  • PUT /api/veiculos/:id
  • DELETE /api/veiculos/:id

4.3 Recursos de Lavagens

  • GET /api/lavagens
  • POST /api/lavagens
  • PUT /api/lavagens/:id
  • DELETE /api/lavagens/:id

4.4 Recursos de Estoque

  • GET /api/produtos
  • POST /api/produtos

  • DELETE /api/produtos/:id

4.5 Movimentações

  • GET /api/movimentacoes

Exportação CSV
GET /api/backup/export

Exporta todas as tabelas em arquivos CSV separados

Importação CSV

5. Segurança

5.1 Controle de Acesso (RBAC)

O sistema implementa Role-Based Access Control com dois perfis: Administrador (acesso completo) e Operador (acesso restrito às operações do dia-a-dia).

RecursoAdminOperador
Dashboard✓✓
Clientes✓✓
Lavagens✓✓
Estoque✓✗
Configurações✓✗
Backup✓✗

5.2 Integridade de Sessão (HMAC)

Sessões armazenadas no LocalStorage são protegidas por assinatura HMAC-SHA256. Qualquer manipulação dos dados invalida a sessão automaticamente.

  • • Assinatura: SHA-256 HMAC
  • • Expiração: 30 dias
  • • Validação: Web Crypto API
  • • Armazenamento: localStorage (signed JSON)

5.3 Validação de Dados

  • • Máscara de telefone: formato (XX) XXXXX-XXXX
  • • Máscara de placa: Mercosul (ABC1D23) ou Antigo (ABC1234)
  • • Sanitização XSS em inputs de texto
  • • Foreign Keys: Integridade referencial ativada
  • • Transações: Suportadas pelo SQLite

5.4 Backup e Consistência

  • • Formato CSV com encoding UTF-8
  • • Ordem de dependências preservada
  • • Foreign keys desabilitados durante import
  • • Transação atômica para restore
  • • Validação de estoque em movimentações
