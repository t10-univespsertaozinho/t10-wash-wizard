Visão Geral do Sistema

Objetivo do Projeto

O Wash Wizard é um software ERP modular construído originalmente para atender aos rígidos requisitos do Projeto Integrador da UNIVESP. Ele provê gestão completa para lava-rápidos, substituindo planilhas por um workflow digital automatizado que cobre controle de frota, gestão de pátio (lavagens), controle de almoxarifado (estoque) e business intelligence (dashboard financeiro).

Evolução Arquitetural

Em sua versão final (acadêmica e offline), o sistema migrou de uma arquitetura Base-as-a-Service (BaaS) com Firebase/Supabase para um ecossistema 100% On-Premise / Local utilizando Node.js e SQLite. Essa transição garante maior governança de dados, velocidade de resposta (latência zero) e total independência de conexão com a internet durante a operação comercial.

Modelagem do Banco de Dados

O esquema relacional é implementado utilizando Constraints e Foreign Keys. Originalmente projetado para PostgreSQL, os datatypes foram transpilados para SQLite (UUIDs e Datetimes utilizando TEXT formatado).

Segurança & AppSec

Client-Side Crypto (HMAC)

Apesar de ser uma simulação acadêmica, a integridade da sessão é resguardada por mecanismos reais. Os dados de usuário guardados em localStorage recebem uma Assinatura HMAC (Hash-based Message Authentication Code) gerada pela Web Crypto API.

// Se o JSON for adulterado:
const isValid = await verifyHMAC(data, signature);
if (!isValid) throw new AuthError('Sessão Inválida');

RBAC (Role-Based Access Control)

O sistema prevê isolamento horizontal e vertical baseado em perfis. A verificação ocorre no roteamento React e nas regras de negócio (API).

  • ADMIN Acesso sistêmico: Exportação de CSVs, Tipos de Lavagem e Estoque de Produtos.
  • USER Acesso operacional: Inserção de Clientes, Veículos, Workflow de Lavagens.
